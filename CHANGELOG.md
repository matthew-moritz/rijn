# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
This project uses [Semantic Versioning](https://semver.org/).

## [0.4.0] - 2026-08-15

First version published to RubyGems.org.

### Added
- Graceful Ctrl+C cancellation handling.
- CI workflow.
- CONTRIBUTING.md, SECURITY.md, and CODE_OF_CONDUCT.md.
- Issue and pull request templates.

### Changed
- Refreshed the README.

## [0.3.0] - 2026-08-15

### Added
- Color support in prompts and error messages.

## [0.2.0] - 2026-08-14

### Added
- Support for 128-bit, 192-bit, and 256-bit key lengths.

## [0.1.0] - 2026-08-13

### Added
- Initial release: `Rijn.generate_key`, `Rijn.encrypt`, `Rijn.decrypt`, and the `rijn` CLI.
